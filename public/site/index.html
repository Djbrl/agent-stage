agent-stage is a coding agent you can actually follow: every file it reads or edits lights up on a map of the project, each step is explained in plain words, and nothing is "done" until the project's own checks pass. Built for open models, and for learning.

How this live demo works

  1. It runs on our own laptop. The app is served from a MacBook Pro (M1) in Dakar, through a secure tunnel. If the laptop is asleep, the demo is offline.
  2. You get a private sandbox. Pressing "Try it live" starts a fresh Docker container just for you, with two small sample projects. The agent really creates files, runs tests and opens pages in a browser, but only inside your sandbox. It has no internet access and is deleted 20 minutes after you leave.
  3. The real model is only on during tests. When our GPU is running, an open model (Qwen3-Coder, on an NVIDIA L40S) does the work. When it's off, a scripted demo model plays a fixed example so you can still see how everything works. The status next to the button tells you which one you'll get.
  4. You're in charge. Commands wait for your approval, and every task can be undone.
You can
Create, edit and delete files; run commands, Node, Python, pytest and git; start a local web server and open it in the agent's browser; use Build, Learn, Ask and Undo.
You can't
Reach the internet from the sandbox (no npm/pip installs, no cloning, no outside websites), reach our laptop or other visitors, change models or keys, or use the Claude engine.
Limits
1 CPU core, 1.5 GB RAM, 512 MB of temporary space, 1 GB of disk (a sandbox that writes more is deleted), 400k model tokens per sandbox, 5 sandboxes at a time.

A real sandbox, just for you

The live demo gives you a private sandbox with sample projects. The agent really edits files, runs tests and uses a browser inside it. It's deleted when you leave.

Done means checked

When the agent says it's finished, the harness runs the project's tests. If they fail, the agent is sent back to fix it.

Learn mode

You design, the agent teaches: it asks for your approach first and only writes code after you approve each step.

Undo anything

A checkpoint before every task. One click puts the files back.

The live demo runs from our own machine during the event, on an open model (Qwen3-Coder) on our GPU. If it's offline, come back a little later.
